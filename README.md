# 🏦 Banking Management System

A console-based **Banking Management System** developed using C programming in **Turbo C**. This project simulates basic banking operations through a menu-driven interface, allowing users to create and manage customer accounts, perform transactions, and maintain account records.

The project was developed to apply fundamental C programming concepts in a practical way, with a focus on functions, structures, file handling, and basic data management.

## ✨ Features

- **Password Authentication:** Basic password-based access to the application.
- **Account Creation:** Register new customers with automatically generated account numbers.
- **Display All Accounts:** View all registered accounts along with customer details and balances.
- **Search Account:** Find a specific account using its account number.
- **Delete Account:** Remove an existing account from the records.
- **Modify Account:** Update stored customer account details.
- **Deposit Money:** Add money to an account and update its balance.
- **Withdraw Money:** Withdraw money with a check for sufficient account balance.
- **Transaction Reports:** View deposit and withdrawal records, including transaction amounts and updated balances.
- **Menu-Driven Interface:** Navigate between different banking operations through a simple console interface.

## 🛠️ Technologies & Concepts Used

- **Language:** C
- **Compiler:** Turbo C
- **Structures:** Used to store customer account details and transaction information.
- **File Handling:** Used to save, read, update, and delete account and transaction records.
- **Functions:** Used to organize different banking operations into separate functions.
- **Loops & Conditional Statements:** Used for menu navigation, record searching, and transaction handling.
- **Switch Case:** Used to execute operations based on the user's menu selection.
- **Basic Console Functions:** Used for screen formatting, text colours, and keyboard input.

## 📁 Files Used

| File | Purpose |
|---|---|
| `bank.txt` | Stores customer account details and balances. |
| `cashbook.txt` | Stores deposit and withdrawal transaction records. |
| `temp.new` | Temporary file used while modifying and deleting account records. |
| `minus.new` | Temporary file used while processing withdrawal-related account updates. |

## ▶️ How to Run

1. Open Turbo C on your computer.
2. Open the project source file (`.CPP`).
3. Compile and run the program.
4. Enter the password `123` when prompted.
5. Choose an option from the main menu to perform the required banking operation.

**Note:** This is an educational project created for learning and practice. It is not intended for real banking operations or secure financial transactions.
